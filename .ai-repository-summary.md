# Repository Summary: PerformerIdentifier-Docs-delta99-a

## Project Overview

**Performer Identifier** is a cross-platform desktop application for privacy-conscious video analysis and face recognition. It runs entirely offline using local ONNX ML models (RetinaFace/SCRFD for detection, ArcFace for recognition) to identify performers in video content. Built with Clean Architecture principles to decouple the AI inference core from the UI layer.

- **Repository**: nam20485/PerformerIdentifier-Docs-delta99-a
- **Status**: Project setup complete; solution builds (0 warnings, 0 errors); tests pass; ready for implementation
- **Type**: Desktop application (cross-platform)
- **Language**: C# (.NET 10)
- **UI Framework**: Avalonia UI v11+ (cross-platform)
- **ML Engine**: ONNX Runtime v1.17+ (DirectML on Windows, CPU fallback elsewhere)
- **Database**: SQLite with Entity Framework Core
- **Video Engine**: FFmpeg (external CLI)
